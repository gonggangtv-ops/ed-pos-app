เต็มจอตลอดเวลา (หน้าสั่งอาหาร / จอครัว)
- วิธีที่ดีที่สุด: ติดตั้งเป็นแอป → Chrome ⋮ → "เพิ่มไปยังหน้าจอหลัก" / "ติดตั้งแอป"
  แล้วเปิดจากไอคอน "สั่งอาหาร" หรือ "จอครัว" บนหน้าจอหลัก = เต็มจอเองทุกครั้ง ไม่ต้องแตะ
- ถ้าเปิดใน Chrome ปกติ: กดปุ่ม ⛶ (หน้าสั่งอาหาร) หรือ "⛶ เต็มจอ" (จอครัว) = ล็อกเต็มจอ
  เครื่องจะจำไว้ · เปิดหน้าใหม่/หลุดจากเต็มจอ แตะหน้าจอครั้งเดียวก็กลับเต็มจอ
  (Chrome ไม่ยอมให้หน้าเว็บเต็มจอเองโดยไม่มีการแตะ) · กดปุ่มเดิมอีกครั้ง = ปลดล็อก
- กันพนักงานออกไปแอปอื่น: ตั้งค่า Android > ความปลอดภัย > "ปักหมุดแอป" (App pinning)

เครื่องพิมพ์ "บางทีต่อไม่ได้ ต้องปิดเปิดเครื่องพิมพ์"
- ตั้งแต่รุ่นนี้ โปรแกรมตัดการเชื่อมต่อเองทุกครั้งหลังส่งงาน และลองส่งซ้ำเองถ้าเครื่องพิมพ์ยังไม่ว่าง
  (สาเหตุเดิม: เครื่องพิมพ์ราคาประหยัดหลายรุ่นไม่ยอมวางสาย สายค้างสะสมจนไม่รับงานใหม่)
- ถ้ายังเป็นอยู่ ตรวจ:
  · ล็อก IP เครื่องพิมพ์ในเราเตอร์ (ถ้า IP เปลี่ยน โปรแกรมหาเครื่องไม่เจอ)
  · เครื่องพิมพ์ Wi-Fi: ปิดโหมดประหยัดพลังงาน/สลีป หรือเปลี่ยนไปใช้สาย LAN จะเสถียรกว่ามาก
  · กด "พิมพ์ทดสอบ" ที่หลังร้าน > เครื่องพิมพ์ ข้อความ error บอกได้ว่าเป็น ไม่ตอบ / ถูกปฏิเสธ / กระดาษหมด
1. ภาพรวม
================================================

- โปรแกรมรันบนแท็บเล็ต Android ผ่านแอป Termux
  เรียกเครื่องนี้ว่า "เครื่องหลัก"
- เครื่องอื่น (มือถือพนักงาน แท็บเล็ตครัว) ไม่ต้องติดตั้งอะไร
  แค่ต่อ Wi-Fi ร้านเดียวกัน แล้วเปิดลิงก์ใน Chrome
- มีเครื่องสำรองได้อีก 1 เครื่อง คอยคัดลอกข้อมูลจากเครื่องหลัก
  ถ้าเครื่องหลักพัง กดปุ่มเดียวให้เครื่องสำรองทำงานแทน
- ข้อมูลทั้งหมดอยู่ในไฟล์ ed-pos/data.json บนเครื่องหลัก
  บันทึกทันทีทุกครั้งที่กด ไฟดับก็ไม่หาย

IP เครื่องหลักตอนติดตั้ง: 192.168.1.34
(ถ้า IP เปลี่ยน ดูหัวข้อ 14)


================================================
2. ติดตั้งครั้งแรก
================================================

ทำบนเครื่องหลักและเครื่องสำรอง เครื่องละครั้ง

2.1 ติดตั้ง Termux
  - ติดตั้งแอป F-Droid (ไฟล์ F-Droid.apk หรือจาก f-droid.org)
  - ค้นหา Termux ใน F-Droid แล้วติดตั้ง
  - ห้ามใช้ Termux จาก Play Store (เวอร์ชันเก่า ลง Node ไม่ได้)

2.2 ลง Node.js (พิมพ์ทีละบรรทัด แล้วกด Enter)
    pkg update -y && pkg upgrade -y
    pkg install nodejs unzip -y
    termux-setup-storage
  - termux-setup-storage จะขออนุญาตเข้าถึงไฟล์ ให้กดอนุญาต
  - ถ้าถาม (y/n) ให้พิมพ์ y
  - ตรวจว่าลงสำเร็จ: node -v  (ต้องขึ้นเลข เช่น v26.4.0)

2.3 แตกไฟล์โปรแกรม
  - ดาวน์โหลด ed-pos.zip ลงแท็บเล็ต (ไปอยู่ในโฟลเดอร์ Download)
  - พิมพ์:
    cd
    unzip -o storage/downloads/ed-pos.zip
    cd ed-pos

2.4 เปิดโปรแกรม
  เครื่องหลัก:
    termux-wake-lock
    node server.js
  เครื่องสำรอง (ใส่ IP ของเครื่องหลัก):
    termux-wake-lock
    node server.js --standby 192.168.1.34:3000

  สำเร็จเมื่อขึ้น "ED POS พร้อมใช้งาน (เครื่องหลัก)"
  หรือ "ED POS เครื่องสำรอง · คัดลอกข้อมูลจาก ..."

2.5 ตั้งค่าครั้งแรกในหลังร้าน
  เปิด http://192.168.1.34:3000/admin.html แล้วทำตามนี้
  - ครั้งแรกจะให้ตั้ง "รหัสเจ้าของร้าน" 4 หลัก (ใส่ 2 ครั้ง) จำไว้ให้ดี
  - รหัสผ่าน: ตั้ง "รหัสพนักงาน" แยกไว้ให้พนักงานใช้เข้าหน้าสั่งอาหาร (หัวข้อ 4.1)
  - ข้อมูลร้าน: ชื่อร้าน เปิด/ปิดปุ่มกลับบ้าน
  - ผังโต๊ะ: จัดตำแหน่งโต๊ะให้ตรงกับหน้าร้าน (หัวข้อ 8)
  - ใบเสร็จ: ใส่โลโก้ ที่อยู่ ข้อความท้ายบิล (หัวข้อ 8)
  - เครื่องพิมพ์: ใส่ IP ทั้ง 2 เครื่อง แล้วกด "พิมพ์ทดสอบ" ทีละเครื่อง
  - เมนู: แก้ราคา เพิ่มเมนูจริงของร้าน
  - ชุดตัวเลือก: ผูกชุด "ความเผ็ด" กับเมนูที่ต้องการ
  - เครื่องสำรอง: ใส่ IP ทั้งสองเครื่อง แล้วกด "บันทึกที่อยู่"

3. เปิดร้านทุกวัน
================================================

1) เปิดเครื่องหลัก → เปิด Termux → พิมพ์
     termux-wake-lock
     cd ~/ed-pos
     node server.js
2) เปิดเครื่องสำรอง → เปิด Termux → พิมพ์
     termux-wake-lock
     cd ~/ed-pos
     node server.js
   (ไม่ต้องใส่ --standby อีก เครื่องจำได้เองว่าเป็นเครื่องสำรอง)
3) เปิดจอครัวใน Chrome
4) มือถือพนักงานเปิดหน้าสั่งอาหาร

ถ้าลง Termux:Boot ไว้ (หัวข้อ 15) ข้อ 1–2 จะเปิดเองตอนเปิดเครื่อง

ระหว่างวัน:
- ใช้แอปอื่นได้ กดปุ่ม Home ได้ แต่ห้ามปิดหรือปัด Termux ทิ้ง
- จะพิมพ์คำสั่งอื่นโดยไม่หยุดโปรแกรม: ใน Termux ปัดจากขอบซ้าย
  แล้วกด NEW SESSION
- หยุดโปรแกรม: ไปหน้าที่รันอยู่ กด CTRL แล้วกด c

4. ลิงก์ของแต่ละหน้า
================================================

บนแท็บเล็ตที่รันโปรแกรมเอง ใช้ localhost แทน IP ได้

  หน้าแรก       http://192.168.1.34:3000
  สั่งอาหาร     http://192.168.1.34:3000/order.html
  จอครัว        http://192.168.1.34:3000/kds.html
  หลังร้าน      http://192.168.1.34:3000/admin.html

เคล็ดลับ: ใน Chrome กด ⋮ → "เพิ่มไปยังหน้าจอหลัก"
จะได้ไอคอนบนหน้าจอ เปิดแบบเต็มจอเอง ไม่ต้องพิมพ์ลิงก์
(iPhone: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอหลัก)

4.1 รหัสผ่าน (PIN 4 หลัก)
  - หน้าสั่งอาหาร: ใส่ "รหัสพนักงาน" (หรือรหัสเจ้าของร้าน)
    เครื่องจะจำไว้ ไม่ต้องใส่ทุกครั้ง กดปุ่ม 🔒 มุมขวาบนเพื่อล็อกเอง
    รายการที่ยังไม่กดส่งยังอยู่ ใส่รหัสแล้วส่งต่อได้
  - หลังร้าน: ใส่ "รหัสเจ้าของร้าน" เท่านั้น
    ล็อกเองเมื่อไม่ได้แตะ 10 นาที หรือกด "🔒 ล็อกหลังร้าน"
  - จอครัว: ไม่ต้องใส่รหัส
  - เปลี่ยนรหัส: หลังร้าน > รหัสผ่าน
    · เปลี่ยนรหัสพนักงานแล้ว ทุกเครื่องหน้าสั่งอาหารต้องใส่รหัสใหม่
    · เปลี่ยนรหัสเจ้าของร้าน ต้องใส่รหัสเดิมยืนยัน
    · "ออกจากระบบทุกเครื่อง" ใช้ตอนมือถือหาย หรือพนักงานลาออก
  - ใส่ผิด 5 ครั้ง ต้องรอ 30 วินาที (ผิดอีก รอนานขึ้น)
  - ลืมรหัสเจ้าของร้าน: ดูหัวข้อ 17 (แก้ปัญหา)
  - ถ้าสลับไปเครื่องสำรอง ทุกเครื่องต้องใส่รหัสอีกครั้ง (รหัสเดิม)


================================================
5. หน้าสั่งอาหาร
================================================

เลือกโต๊ะ
- หน้าเลือกโต๊ะแสดงเป็นผังร้าน ตำแหน่งเหมือนหน้าร้านจริง
  (ปุ่ม "รายการ" มุมขวาบน = สลับเป็นปุ่มเรียงตามเลข มือถือเริ่มที่มุมมองนี้)
- โต๊ะสีส้ม = มีบิลเปิดอยู่ แสดงยอดและเวลาที่นั่งมา

ซื้อกลับบ้านทั้งบิล
- ใต้ผังมีปุ่ม "+ กลับบ้าน" กดแล้วพิมพ์เลขคิวหรือชื่อลูกค้าเอง
  เช่น 12 หรือ คุณสมชาย (ระบบเสนอเลขถัดไปให้ แก้ได้)
- บิลกลับบ้านที่ยังไม่จ่ายจะขึ้นเป็นปุ่มสีส้มข้างปุ่ม "+ กลับบ้าน"
- บนจอครัว บิลกลับบ้านที่ยังไม่จ่ายเงินจะมีป้ายแดง "💰 ยังไม่ได้ชำระ" และกรอบการ์ดสีแดง
  เพื่อให้ครัวรู้ว่าลูกค้ายังไม่จ่าย ก่อนส่งของให้ต้องเก็บเงินก่อน
  พอกดชำระเงินที่หน้าสั่งอาหาร ป้ายจะหายไปเองภายในไม่กี่วินาที (ไม่ต้องรีเฟรช)
  ถ้าจ่ายแค่บางส่วน (แยกจ่าย) ป้ายยังอยู่จนกว่าจะจ่ายครบ
- ใช้ชื่อซ้ำกับบิลที่เปิดอยู่ = เปิดบิลเดิมต่อ
- ตอน "ย้าย/รวมโต๊ะ" ก็มีปุ่ม "+ กลับบ้าน (ใส่เลขเอง)" ให้เลือก

เพิ่มเมนู
- แตะเมนู → เลือกตัวเลือก (เนื้อสัตว์ ความเผ็ด ฯลฯ) → จำนวน
  → ทานที่ร้าน / กลับบ้าน → หมายเหตุ → กด "เพิ่ม"
- ตัวเลือกที่มีคำว่า "ต้องเลือก" ต้องเลือกก่อนถึงจะกดเพิ่มได้
- ตัวเลือกสีแดง (เช่น แพ้อาหาร) จะเตือนครัวเป็นสีแดง
- เมนูที่ขึ้นว่า "หมด" สั่งไม่ได้ (เปิดขายคืนได้ในหลังร้าน)

กลับบ้านแม้นั่งที่โต๊ะ
- ตอนเพิ่มเมนู เลือก "กลับบ้าน (ใส่กล่อง)"
- หรือในรายการที่ยังไม่ส่ง แตะปุ่ม "ทานที่ร้าน / กลับบ้าน" ทีละจาน
- มีลิงก์ "กลับบ้านทั้งหมด" ถ้ามีหลายรายการ
- ครัวเห็นหมายเหตุ "กลับบ้าน" ใบสั่งพิมพ์ ">> ใส่กล่องกลับบ้าน <<"

เมนูพิเศษ (ใส่ชื่อและราคาเอง)
- ปุ่ม "+ เมนูพิเศษ" กรอบเส้นประ อยู่ท้ายเมนูทุกหมวด
- ใส่ชื่อ ราคา จำนวน เลือกส่งครัวหรือหน้าร้าน
- ไม่ถูกบันทึกเป็นเมนูถาวร ถ้าสั่งบ่อยควรเพิ่มเป็นเมนูจริงในหลังร้าน

ส่งออเดอร์
- กด "ส่งออเดอร์" → ใบสั่งพิมพ์ออกเครื่องที่ตั้งไว้ และขึ้นจอครัว
- รายการที่ยังไม่กดส่ง จะยังไม่ไปถึงครัว

ยกเลิก / ย้ายโต๊ะ
- กด ✕ ที่รายการที่สั่งแล้ว = ยกเลิก (ครัวได้รับแจ้งเตือน)
- ลูกค้าสั่งแล้วไม่เอาทั้งโต๊ะ: กด "ยกเลิกทั้งโต๊ะ (ลูกค้าไม่เอาแล้ว)" ใต้ปุ่มชำระเงิน
  เลือกเหตุผล → ทุกจานถูกยกเลิก จอครัวเตือน "ยกเลิกทั้งโต๊ะ" พิมพ์ใบยกเลิก แล้วโต๊ะกลับมาว่าง
  ไม่นับเป็นยอดขาย ดูย้อนหลังได้ที่หลังร้าน > ยอดขาย (ใต้ตารางบิล)
  ถ้าครัวทำบางจานเสร็จแล้วและจะเก็บเงิน ให้กด ✕ เฉพาะจานที่ไม่เอา แล้วชำระเงินตามปกติ
- ถ้ายกเลิกจนไม่มียอดค้างแล้ว ปุ่มชำระเงินจะเปลี่ยนเป็น "ปิดโต๊ะ" กดเพื่อให้โต๊ะว่าง
  (ใช้ได้ทั้งกรณียกเลิกครบทุกจาน และกรณีแยกจ่ายไปแล้ว แต่จานที่เหลือถูกยกเลิกหมด)
- โต๊ะที่รับเงินไปบางส่วนแล้ว ยกเลิกทั้งโต๊ะไม่ได้ ให้ยกเลิกทีละจานที่ยังไม่จ่าย
- "ย้าย/รวมโต๊ะ" ถ้าโต๊ะปลายทางมีบิลอยู่ จะรวมเป็นบิลเดียว
- "พิมพ์ใบแจ้งยอด" = ใบให้ลูกค้าดูยอดก่อนจ่าย
- แก้รายการที่ยังไม่ส่ง: แตะชื่อรายการ หรือปุ่ม ✎ → เปลี่ยนเนื้อสัตว์/ขนาด/จำนวน/หมายเหตุ/กลับบ้าน แล้วกด "บันทึก"
- "🖨 พิมพ์ใบสั่งซ้ำ" (หัวข้อ "สั่งแล้ว") = ใบสั่งไม่ออก/ใบหาย · เลือกจาน (ค่าเริ่มต้น = รอบที่ส่งล่าสุด)
  ใบพิมพ์ซ้ำมีหัว "*** พิมพ์ซ้ำ ***" ครัวจะรู้ว่าไม่ใช่ออเดอร์ใหม่ · ไม่เพิ่มยอด ไม่ขึ้นจอครัวซ้ำ
- หมวดเมนูอยู่แถบซ้าย ตัวเลขสีส้มบนหมวด = จำนวนที่เลือกไว้แต่ยังไม่ส่ง
- ช่อง "ค้นหาเมนู" ด้านบน พิมพ์ไทยหรืออังกฤษก็ได้ เช่น ลูกค้าบอก "pad thai" พิมพ์ pad
- "ภาษาใบเสร็จ" (ไทย / EN / 2 ภาษา) เหนือปุ่มย้ายโต๊ะ = เลือกภาษาของใบแจ้งยอดและใบเสร็จเฉพาะบิลนี้
  เช่น ร้านตั้ง EN ไว้ แต่โต๊ะนี้เป็นลูกค้าคนไทย กด "ไทย" (ในหน้าชำระเงินก็เปลี่ยนได้) ดูหัวข้อ 9.5

บนมือถือ
- แถบด้านล่างแสดงยอดรวม แตะเพื่อเปิดบิล
- ปุ่ม ⛶ มุมขวาบน = เต็มจอ (iPhone ใช้ "เพิ่มไปยังหน้าจอหลัก" แทน)


================================================
6. ชำระเงินและแยกบิล
================================================

กด "ชำระเงิน / แยกบิล" แล้วเลือกแบบ

ทั้งบิล
- เลือกวิธีจ่าย: เงินสด / โอน / บัตร
- เงินสด: ใส่ยอดที่รับมา ระบบคำนวณเงินทอน (ไม่ใส่ก็ได้)
- บัตร: บวกค่าธรรมเนียม 3% ให้อัตโนมัติ พิมพ์แยกบรรทัดในใบเสร็จ

แยกตามรายการ (แต่ละคนจ่ายของที่ตัวเองกิน)
- กด + / − เลือกจานของคนนี้ แยกจำนวนได้
  (เช่น กะเพรา 2 จาน จ่ายคนละจาน)
- กด "รับเงิน" → พิมพ์ใบเสร็จของคนนั้น
- ทำซ้ำกับคนถัดไปจนครบ บิลปิดเองเมื่อจ่ายครบ

หารเท่า
- เลือกจำนวนคน ระบบปัดเป็นบาทเต็ม คนสุดท้ายจ่ายส่วนที่เหลือพอดี
  (เช่น 100 หาร 3 = 34, 34, 32)
- แต่ละคนเลือกวิธีจ่ายของตัวเองได้

ข้อควรรู้
- หลังจ่ายแต่ละคน วิธีจ่ายกลับเป็นเงินสดเสมอ กันกดผิด
- เริ่มหารเท่าแล้ว เปลี่ยนเป็นแยกตามรายการไม่ได้
- จานที่จ่ายแล้วยกเลิกไม่ได้
- โต๊ะที่เริ่มแยกจ่ายแล้ว รวมกับโต๊ะอื่นไม่ได้ (ย้ายไปโต๊ะว่างได้)
- ยอดที่รับบางส่วนจะเข้ายอดขายเมื่อปิดบิลครบทั้งโต๊ะ

7. จอครัว
================================================

- เปิดค้างไว้ที่แท็บเล็ตครัว กด "เต็มจอ" ได้
- มีหลายจอ (เช่น ครัว + บาร์น้ำ): เลือกจอจากช่องข้างคำว่า "ครัวรวมจาน" (หัวข้อ 9)
- แตะจาน = ทำเสร็จ · "เสร็จทั้งโต๊ะ" = เสร็จหมดทั้งโต๊ะ
- แตะ ✓ สีเขียวของจานที่เสร็จ = ย้อนกลับไปรอทำ
- ป๊อปอัพ "ทำรวม" = เมนูเดียวกันที่หลายโต๊ะสั่ง ทำพร้อมกันได้
  (แตะในป๊อปอัพ = เสร็จทั้งชุด)
- ข้อความสีแดง = หมายเหตุ / แพ้อาหาร / กลับบ้าน
- แจ้งเตือนยกเลิกเมนู ย้ายโต๊ะ ขึ้นเป็นป้ายแดงพร้อมเสียง
- แท็บ "เสร็จแล้ว" มีสรุปวันนี้ และปุ่ม "เรียกกลับ"

อ่านออกเสียง
- ต่อลำโพงบลูทูธกับแท็บเล็ต
- กด "อ่านออกเสียง: เปิด" แล้วกด ⚙️ เลือกเมนูที่ให้อ่าน
- หลังรีเฟรชหน้า ต้องแตะหน้าจอ 1 ครั้งก่อน เสียงถึงจะทำงาน
- ถ้าไม่มีเสียงภาษาไทย: ตั้งค่า Android → ระบบ → ภาษา
  → การอ่านออกเสียงข้อความ → ติดตั้งเสียงภาษาไทย

การตั้งค่าบนจอครัว (เสียง ทำรวม ธีม ขนาด)
เก็บในเบราว์เซอร์ของเครื่องนั้น ถ้าเปิดจอครัวบนเครื่องอื่นต้องตั้งใหม่

8. หลังร้าน
================================================

ยอดขาย
- เลือกวันนี้ / เมื่อวาน / 7 วัน / 30 วัน / เดือนนี้ / เลือกวัน
- ยอดขาย จำนวนบิล เฉลี่ยต่อบิล จานที่ขาย จานที่ยกเลิก
- กราฟรายชั่วโมง (วันเดียว) หรือรายวัน (หลายวัน)
- แยกตามวิธีจ่าย ตามหมวด เมนูขายดี (แตะเพื่อดูว่าขายแบบไหน)
- รายการบิล + ปุ่มพิมพ์ใบเสร็จซ้ำ (บิลวันนี้)
- ดาวน์โหลด CSV เปิดใน Excel ได้
- บิลรายตัวเก็บ 7 วัน ยอดรวมรายวันเก็บถาวร

เมนู
- แตะเมนูเพื่อแก้: ชื่อ หมวด ราคา ตัวเลือก เครื่องพิมพ์ จอครัว (หัวข้อ 9)
- สวิตช์ท้ายแถว = มีขาย / หมด
- ▲▼ = เลื่อนลำดับ
- กลุ่มตัวเลือก: ตั้งได้ว่า เลือก 1 / หลายอย่าง, ต้องเลือก,
  เตือนครัว (สีแดง) และบวกราคาแต่ละตัวเลือก
- "บันทึกเป็นชุดสำเร็จรูป" = เก็บกลุ่มไปใช้กับเมนูอื่น
- "ทำสำเนา" = ก๊อปเมนูไปแก้เป็นเมนูใหม่

ชุดตัวเลือก
- ชุดที่ใช้ซ้ำหลายเมนู เช่น ความเผ็ด แพ้อาหาร ความหวาน
- แก้ที่เดียว ทุกเมนูที่ใช้ชุดนั้นเปลี่ยนตาม
- ในหน้าแก้ชุด ติ๊กเลือกเมนูที่จะใช้ หรือกด "เลือกทั้งหมวด"
- หมายเหตุด่วน (ท้ายหน้า) = ปุ่มหมายเหตุที่ขึ้นทุกเมนู

หมวดหมู่
- เรียงลำดับแท็บในหน้าสั่งอาหาร เปลี่ยนชื่อ เพิ่ม ลบ
- ลบหมวดได้เมื่อไม่มีเมนูอยู่ในหมวด

การชำระเงิน
- เปิด/ปิด เงินสด โอน บัตร
- ตั้งค่าธรรมเนียมบัตร (%) ใส่ 0 ถ้าไม่เก็บ

ผังโต๊ะ
- หน้าตั้งค่าที่จัดโต๊ะให้ตรงหน้าร้าน (ผังเริ่มต้นตามผังร้านที่ให้มา)
- ลากโต๊ะเพื่อย้าย ลากสี่เหลี่ยมเขียวมุมล่างขวาเพื่อปรับขนาด
  หรือพิมพ์ ขนาด/ตำแหน่ง ในช่องขวามือ · ปุ่มลูกศรบนคีย์บอร์ดขยับทีละนิด
- "+ โต๊ะ" เพิ่มโต๊ะ (ชื่อพิมพ์เองได้ เช่น 7กลาง, 19//2)
  "+ ฉากกั้น" ใส่ผนัง/ฉาก · "+ ป้ายข้อความ" ใส่คำอธิบายโซน
- "คัดลอก" ทำโต๊ะซ้ำจากโต๊ะที่เลือก · "ลบ" เอาออก
- "ชิดตาราง" ช่วยให้วางเป็นระเบียบ (ปิดได้ถ้าอยากวางละเอียด)
- ชื่อโต๊ะห้ามซ้ำ และห้ามขึ้นต้นด้วย TA (ใช้กับบิลกลับบ้าน)
- แก้เสร็จต้องกด "บันทึกผัง" แล้วรีเฟรชหน้าสั่งอาหาร
- ลบโต๊ะที่ยังมีบิลค้าง บิลนั้นจะขึ้นในส่วน "โต๊ะนอกผังที่มีบิลค้าง"
  ไม่หาย ปิดบิลได้ตามปกติ

ใบเสร็จ
- ตัวอย่างใบเสร็จอยู่ทางขวา เปลี่ยนค่าแล้วเห็นทันที (ขาวดำเหมือนที่พิมพ์จริง)
- โลโก้: "เลือกรูป…" ปรับขนาดด้วยแถบเลื่อน
    ชนิด "คมชัด" = โลโก้ลายเส้น/ตัวหนังสือ (ตัดเป็นขาว-ดำ)
    ชนิด "รูปถ่าย" = รูปที่มีเฉดสี (พิมพ์เป็นจุดละเอียดให้เห็นโทนเทา)
  แนะนำรูปพื้นขาว คอนทราสต์สูง ไม่ต้องใหญ่ ระบบย่อให้เอง
- ชื่อร้านและขนาดตัวอักษร · บรรทัดใต้ชื่อร้าน (ที่อยู่ โทร เลขผู้เสียภาษี)
- เปิด/ปิดแสดง ชื่อโต๊ะ วันที่เวลา เลขที่ใบเสร็จ
- ท้ายใบเสร็จ: ข้อความ + รูป (เช่น QR พร้อมเพย์ หรือ LINE) ใช้ชนิด "คมชัด"
- "พิมพ์ทดสอบ" = พิมพ์ใบเสร็จตัวอย่างออกเครื่องพิมพ์ใบเสร็จเพื่อดูของจริง
- แก้เสร็จกด "บันทึกใบเสร็จ"

ข้อมูลร้าน · เครื่องพิมพ์ · สำรองข้อมูล · เครื่องสำรอง
- ข้อมูลร้าน: ชื่อร้าน และสวิตช์เปิด/ปิดปุ่ม "+ กลับบ้าน"
- เครื่องพิมพ์ จอครัว สำรองข้อมูล เครื่องสำรอง ดูหัวข้อ 9, 10, 13


================================================
9. เครื่องพิมพ์และจอครัวหลายจอ
================================================

เครื่องพิมพ์ (หลังร้าน > เครื่องพิมพ์)
- เพิ่มได้ไม่จำกัด กด "+ เพิ่มเครื่องพิมพ์" ใส่ชื่อ IP พอร์ต ขนาดกระดาษ
  แล้วกด "พิมพ์ทดสอบ" (ร้านเดิมมี หน้าร้าน + ครัว ให้แล้ว)
- "ใบสั่ง/ครั้ง" = ส่งออเดอร์ 1 ครั้ง เครื่องนี้พิมพ์ใบสั่งกี่ใบ
  (ใบยกเลิก / ย้ายโต๊ะ พิมพ์ใบเดียวเสมอ)
- ใบเสร็จ: เลือกได้ว่าออกเครื่องไหน และพิมพ์กี่ใบ
  (ใบแจ้งยอดก่อนจ่าย พิมพ์ใบเดียว)
- ตาราง "เมนูไหนออกเครื่องไหน": ติ๊กได้หลายเครื่องต่อเมนู
  เช่น ของทอด ติ๊ก ครัว + หน้าร้าน · ติ๊กที่ชื่อหมวด = ทั้งหมวด
  เมนูที่ไม่ติ๊กเลย = ไม่พิมพ์ใบสั่ง
- ลบเครื่องพิมพ์ → เมนูที่เคยออกเครื่องนั้นจะไม่พิมพ์ที่เครื่องนั้นอีก
- แก้เสร็จกด "บันทึกเครื่องพิมพ์"
- ปิด "พิมพ์ใบสั่งทุกครั้งที่ส่งออเดอร์" ถ้าใช้จอครัวอย่างเดียว
- ถ้าพิมพ์ไม่ออก จะถามให้ลองใหม่ ออเดอร์ไม่หาย

ตัวอย่าง: เพิ่มเครื่องพิมพ์บาร์น้ำ
  1) ต่อเครื่องพิมพ์เข้า Wi-Fi/LAN ร้าน ล็อก IP ในเราเตอร์
  2) หลังร้าน > เครื่องพิมพ์ > "+ เพิ่มเครื่องพิมพ์" ชื่อ "บาร์น้ำ" ใส่ IP
  3) ในตาราง ติ๊กช่อง "บาร์น้ำ" ที่หมวดเครื่องดื่ม
  4) บันทึก แล้วกด "พิมพ์ทดสอบ"

จอครัวหลายจอ (หลังร้าน > จอครัว)
- เพิ่มจอ เช่น "บาร์น้ำ" แต่ละจอเห็นเฉพาะเมนูที่ติ๊กให้จอนั้น
- แต่ละจอมีลิงก์ของตัวเอง เช่น  /kds.html?screen=k1
  กด "คัดลอก" แล้วเปิดลิงก์นั้นบนแท็บเล็ตของจอนั้น
  หรือบนหน้าจอครัว เลือกจอจากช่องข้างคำว่า "ครัวรวมจาน"
  (มีตัวเลือก "ทุกจอรวมกัน" ด้วย) แท็บเล็ตจะจำจอที่เลือกไว้
- เมนูที่ไม่ติ๊กจอไหนเลย = ไม่ขึ้นจอ ถือว่าเสร็จทันที (ใช้ใบที่พิมพ์แทน)
- "เสร็จทั้งโต๊ะ" มีผลเฉพาะจอที่กด จอบาร์ไม่หายถ้าครัวกดเสร็จ
- ประวัติแท็บ "เสร็จแล้ว" แยกเก็บตามจอ

แก้ทีละเมนูก็ได้: หลังร้าน > เมนู > แตะเมนู > "พิมพ์ใบสั่งที่" / "ขึ้นจอครัว"
(แตะปุ่มชื่อเครื่อง/จอ เพื่อเลือกหรือไม่เลือก)
เมนูพิเศษ (พนักงานใส่ชื่อ-ราคาเอง) เลือกเครื่องพิมพ์และจอได้ตอนสั่ง

9.5 ใบแจ้งยอด / ใบเสร็จภาษาอังกฤษ (ลูกค้าต่างชาติ)
- เฉพาะใบที่ลูกค้าได้เท่านั้นที่เป็นภาษาอังกฤษ
  หน้าสั่งอาหาร จอครัว และใบสั่งในครัวยังเป็นภาษาไทยเหมือนเดิม
- ขั้นที่ 1: หลังร้าน > ชื่อภาษาอังกฤษ
  ใส่ชื่ออังกฤษของเมนูและตัวเลือก (หมู ไก่ เผ็ดน้อย ...) คำเดียวกันใส่ครั้งเดียวใช้ได้ทุกเมนู
  กด "เติมคำแนะนำในช่องที่ว่าง" ให้ระบบเติมคำทั่วไปให้ แล้วตรวจ/แก้ให้ตรงกับอาหารร้าน
  ตัวเลขข้างเมนู "ชื่อภาษาอังกฤษ" = จำนวนคำที่ยังไม่ได้แปล
  เพิ่มเมนูใหม่ทีหลัง อย่าลืมกลับมาใส่ชื่ออังกฤษ (ถ้าไม่ใส่ ใบเสร็จอังกฤษจะพิมพ์ชื่อนั้นเป็นภาษาไทย)
- ขั้นที่ 2: หลังร้าน > ใบเสร็จ > ภาษา เลือกภาษาเริ่มต้น
    ไทย    = แบบเดิม
    EN     = ภาษาอังกฤษทั้งใบ (Table 5, TOTAL, Cash, Change ...)
    2 ภาษา = ชื่อเมนูอังกฤษ มีชื่อไทยตัวเล็กใต้แต่ละรายการ หัวข้อเป็น "TOTAL / รวม"
  ใส่ "บรรทัดใต้ชื่อร้าน (ภาษาอังกฤษ)" และ "ข้อความท้ายใบเสร็จ (ภาษาอังกฤษ)" ได้
  ถ้าเว้นว่างจะใช้ข้อความภาษาไทย · ชื่อร้านใช้ช่องเดียวกันทุกภาษา (ใส่ทั้งไทยและอังกฤษในชื่อได้)
- เปลี่ยนเฉพาะบิล: หน้าสั่งอาหาร > "ภาษาใบเสร็จ" หรือในหน้าชำระเงิน
  ระบบจำภาษาไว้กับบิล พิมพ์ใบเสร็จซ้ำจากหลังร้านก็ออกเป็นภาษาเดิม
- บิลเก่าก็พิมพ์ซ้ำเป็นอังกฤษได้ เพราะระบบแปลตอนพิมพ์

9.6 ตารางราคา (ราคาตามเนื้อสัตว์ × ขนาด S/M/L)
- ใช้เมื่อราคาขึ้นกับตัวเลือก 2 อย่างพร้อมกัน เช่น ข้าวผัด ไก่/หมู S 120 แต่ ทะเล S 150
- หลังร้าน > เมนู > แตะเมนู > "ตารางราคา" เลือกแถว (เช่น เนื้อสัตว์) และคอลัมน์ (เช่น ขนาด)
  แล้วใส่ราคาเต็มของจานในแต่ละช่อง · ช่องว่าง = ไม่มีขาย เช่น ผัดน้ำมันหอยไม่มีเจ
  พนักงานจะไม่เห็นปุ่ม "เจ" ในเมนูนั้น
- ใช้แค่แถวอย่างเดียวก็ได้ (คอลัมน์ "ไม่มี") เช่น เบียร์ ขวดเล็ก 60 / ขวดใหญ่ 100
- หน้าสั่งอาหาร: ปุ่มเนื้อสัตว์และขนาดแสดงราคาจริงให้เลย เปลี่ยนขนาดแล้วราคาบนปุ่มเปลี่ยนตาม
- เนื้อสัตว์ผสม: หลังร้าน > ชุดตัวเลือก > เนื้อสัตว์ > เลือก "หลายอย่าง" > บันทึก
  พนักงานแตะได้หลายปุ่ม เช่น ไก่ + กุ้ง ระบบคิดราคาของตัวที่แพงที่สุด (ไก่ M 150, กุ้ง M 200 → 200)
  ต้องเลือกอย่างน้อย 1 อย่าง · เมนูที่ไม่มีเจ จะผสมเจไม่ได้
- ระวัง: ถ้าเปลี่ยนชื่อตัวเลือกในชุดตัวเลือก (เช่น "ไก่/หมู" เป็น "ไก่") ต้องเข้าไปใส่ราคาในตารางของเมนูนั้นใหม่

9.65 ตัวเลือกพิมพ์แยกไปอีกเครื่อง (เช่น ไข่ดาว → หน้าร้าน)
- ในชุดตัวเลือก หรือกลุ่มตัวเลือกของเมนู แต่ละตัวเลือกมีช่อง "พิมพ์แยกที่"
  เลือกเครื่อง เช่น ไข่ดาว → หน้าร้าน (ไม่แยก = พิมพ์รวมกับจานตามปกติ)
- สั่ง ผัดกะเพรา หมู M + ไข่ดาว จำนวน 2:
    เครื่องครัว:   2 x ผัดกะเพรา หมู M ไข่ดาว
    เครื่องหน้าร้าน: 2 x ไข่ดาว   * ของ ผัดกะเพรา หมู M
- ยกเลิกจาน → ใบยกเลิกไปทั้งสองเครื่อง · ย้ายโต๊ะ → ทั้งสองเครื่องได้ใบแจ้งย้าย
- จานที่สั่งไปก่อนตั้งค่านี้ไม่ได้รับผล

9.68 หมวดใหญ่ (หมวดย่อยอยู่ข้างใน)
- หลังร้าน > หมวดหมู่ > "หมวดใหญ่" พิมพ์ชื่อ เช่น อาหาร แล้วกด "เพิ่มหมวดใหญ่"
- ในรายการ "หมวด" ด้านล่าง เลือกช่องหมวดใหญ่ของแต่ละหมวด เช่น ข้าว → อาหาร, ปู → ทะเล
  หมวดที่ไม่ได้เลือกจะอยู่ใน "อื่นๆ" · ลบหมวดใหญ่ เมนูและหมวดย่อยไม่หาย
- หน้าสั่งอาหาร: แถบซ้ายแสดงหมวดใหญ่เป็นหัวข้อ แตะหัวข้อแล้วหมวดย่อยกางออกข้างใต้
  แตะหมวดย่อย (ข้าว / เส้น / ผัด …) เพื่อดูเมนูหมวดนั้น · แตะหัวข้อซ้ำ = หุบ
  ตัวเลขสีส้มบนหัวข้อที่หุบอยู่ = จำนวนที่เลือกไว้ในหมวดใหญ่นั้น ยังไม่ส่ง
- ไม่ตั้งหมวดใหญ่เลย = แถบซ้ายแสดงทุกหมวดเหมือนเดิม
- ลำดับหมวดใหญ่เปลี่ยนด้วยปุ่ม ▲▼ ของหมวดใหญ่ · ลำดับหมวดย่อยตามรายการ "หมวด"

9.7 นำเข้าเมนูจากไฟล์
- หลังร้าน > เมนู > "นำเข้าเมนูจากไฟล์" เลือกไฟล์ .json (เช่น ไฟล์เมนูที่ทำจากรูปเมนูร้าน)
- เมนูและหมวดเดิมจะถูกแทนที่ทั้งหมด บิลที่เปิดอยู่และยอดขายเดิมไม่กระทบ
- อาหาร → พิมพ์ที่เครื่องครัวและขึ้นจอครัว · เครื่องดื่ม → พิมพ์ที่หน้าร้าน ไม่ขึ้นจอ
  แก้ทีหลังได้ที่ เครื่องพิมพ์ / จอครัว
- ชื่อภาษาอังกฤษในไฟล์ถูกเพิ่มให้ด้วย

10. เครื่องสำรอง
================================================

ตั้งครั้งแรก
- ติดตั้งตามหัวข้อ 2 แล้วรัน
    node server.js --standby 192.168.1.34:3000
- หลังร้าน → เครื่องสำรอง → ใส่ IP ทั้งสองเครื่อง → บันทึกที่อยู่
  (ถ้าไม่ทำ มือถือจะไม่รู้ว่าเครื่องสำรองอยู่ไหน)
- มือถือทุกเครื่องเปิดหน้าสั่งอาหาร 1 ครั้งตอนที่ทั้งสองเครื่องเปิดอยู่

เครื่องสำรองต้องรัน Termux ค้างไว้ตลอดเวลาร้านเปิด

เช็กสถานะ
- หลังร้าน → เครื่องสำรอง
    เขียว = เชื่อมอยู่ · แดง = หายไป (ไปเปิด Termux ใหม่)
- บนเครื่องสำรอง เปิด http://localhost:3000
  ดูเวลาคัดลอกล่าสุดและจำนวนโต๊ะที่เปิด

เมื่อเครื่องหลักพัง
1) รอประมาณ 10 วินาที มือถือขึ้นแถบแดง "เครื่องหลักไม่ตอบ"
2) กด "ใช้เครื่องสำรองแทน" บนมือถือเครื่องไหนก็ได้
   หรือบนเครื่องสำรอง เปิด http://localhost:3000
   กด "ใช้เครื่องนี้เป็นเครื่องหลัก"
3) ทุกหน้าจอย้ายไปเครื่องสำรองเอง โต๊ะที่ค้างอยู่ครบ
   รายการที่ยังไม่ได้ส่งติดไปด้วย
4) ถ้าจอครัวอยู่บนเครื่องที่พัง ให้เปิดจอครัวบนเครื่องสำรองแทน
   http://localhost:3000/kds.html

ปุ่มสลับจะกดไม่ได้ ถ้าเครื่องหลักยังทำงานอยู่ (กันข้อมูลแยกสองชุด)
อาจหายสิ่งที่กดในช่วง 2 วินาทีสุดท้ายก่อนเครื่องหลักพัง

เมื่อซ่อมเครื่องเดิมเสร็จ
- เปิด Termux → cd ~/ed-pos → node server.js
- มันจะเปลี่ยนตัวเองเป็นเครื่องสำรองเอง (สองเครื่องสลับบทบาทกัน)
- ใช้แบบนี้ต่อได้เลย ไม่ต้องสลับกลับ

อยากให้เครื่องเดิมกลับมาเป็นเครื่องหลัก
1) รอให้เครื่องเดิมเป็นเครื่องสำรองและคัดลอกข้อมูลครบ
2) ตอนร้านว่าง กด CTRL+c ที่เครื่องหลักปัจจุบัน
3) ที่เครื่องเดิม เปิด http://localhost:3000
   กด "ใช้เครื่องนี้เป็นเครื่องหลัก"
4) เปิดเครื่องที่หยุดกลับมาด้วย node server.js

แก้ IP เครื่องหลักในเครื่องสำรอง
- ที่เครื่องสำรอง: CTRL+c แล้ว
    node server.js --standby IPใหม่:3000
- ที่หลังร้าน → เครื่องสำรอง: แก้ IP ให้ตรง → บันทึกที่อยู่

ห้ามคัดลอก data.json และ role.json จากเครื่องหลักไปเครื่องสำรอง

12. อัปเดตโปรแกรม
================================================

ข้อมูลไม่หาย เพราะไฟล์ zip ไม่มี data.json อยู่ข้างใน

1) ลบ zip เก่า (ทำก่อนดาวน์โหลดใหม่)
     rm ~/storage/downloads/ed-pos.zip
2) ดาวน์โหลด ed-pos.zip ตัวใหม่
3) กด CTRL+c หยุด ED POS
4) สำรองข้อมูล
     cp ~/ed-pos/data.json ~/storage/downloads/ed-pos-backup.json
5) แตกไฟล์ทับ แล้วเปิดใหม่
     cd ~
     unzip -o ~/storage/downloads/ed-pos.zip
     cd ed-pos
     node server.js
6) รีเฟรชทุกหน้าจอ (จอครัว มือถือ หลังร้าน)

ถ้ามีเครื่องสำรอง ต้องอัปเดตด้วย ให้ทั้งสองเครื่องเป็นเวอร์ชันเดียวกัน
(ถ้าเครื่องหลักพังแล้วสลับไปเครื่องสำรองที่เวอร์ชันเก่า หน้าจอจะเป็นแบบเก่า)
- ทำข้อ 1–3 และ 5 ที่เครื่องสำรองก่อน (ไม่ต้องสำรองข้อมูล ข้อมูลดึงจากเครื่องหลัก)
- แล้วค่อยทำข้อ 1–6 ที่เครื่องหลัก ตอนร้านว่าง
- ไม่ต้องพิมพ์ --standby ใหม่ เครื่องสำรองจำบทบาทตัวเองไว้ (ไฟล์ role.json ไม่อยู่ใน zip)
- เสร็จแล้วเข้า หลังร้าน > เครื่องสำรอง ดูว่าจุดเขียว

ถ้าลืมลบ zip เก่า ไฟล์ใหม่จะชื่อ "ed-pos (1).zip" ใช้คำสั่งนี้แทน
     unzip -o ~/storage/downloads/"ed-pos (1).zip"

13. สำรองและกู้คืนข้อมูล
================================================

อัตโนมัติ
- โปรแกรมสำรองวันละไฟล์ใน ed-pos/backup (เก็บ 30 วัน)
- แต่อยู่ในเครื่องเดียวกัน ถ้าเครื่องพังจะหายไปด้วย

สำรองเอง (แนะนำสัปดาห์ละครั้ง)
- หลังร้าน → สำรองข้อมูล → ดาวน์โหลด
  ทำจากมือถือเครื่องไหนก็ได้ ได้ไฟล์ .json
- หรือใน Termux:
    cp ~/ed-pos/data.json ~/storage/downloads/ed-pos-backup.json
  (รันซ้ำจะเขียนทับสำเนาเดิม)
- ส่งไฟล์สำรองไปเก็บที่อื่น เช่น LINE ตัวเอง หรือ Google Drive

กู้คืน (ตั้งแต่ ed-pos26 ทำจากหลังร้านได้)
- หลังร้าน → สำรองข้อมูล → กู้คืนข้อมูล
  · "เลือกไฟล์…" = ไฟล์ ed-pos-วันที่.json ที่ดาวน์โหลดไว้ (บนแท็บเล็ตอยู่ใน Download)
  · หรือเลือกจาก "สำรองในเครื่องหลัก" (อัตโนมัติรายวัน 30 วัน / ข้อมูลก่อนกู้คืนแต่ละครั้ง)
- ดูสรุปไฟล์ (ร้าน จำนวนเมนู บิล วันที่ข้อมูลล่าสุด) → ใส่รหัสเจ้าของร้าน → "กู้คืนข้อมูลนี้"
- ข้อมูลทั้งร้านกลับไปเป็นเหมือนในไฟล์ ยอดขาย/บิล/การแก้เมนูที่เกิดหลังจากนั้นหายไป
- ข้อมูลปัจจุบันถูกเก็บเป็น backup/before-restore-วันเวลา.json ก่อนทุกครั้ง
  กู้ผิดไฟล์ → เลือก "ก่อนกู้คืน · ..." ในรายการ แล้วกู้คืนอีกครั้งเพื่อย้อนกลับ
- รหัส PIN ใช้ของปัจจุบัน ทุกเครื่องไม่ต้องใส่รหัสใหม่ · เครื่องสำรองดึงข้อมูลใหม่ไปเอง
- ทำได้เฉพาะตอนเครื่องหลักทำงาน (เครื่องสำรองกู้คืนไม่ได้)
- อยากได้คืนเฉพาะเมนู ใช้ เมนู → นำเข้าเมนูจากไฟล์ แทน (ยอดขายไม่กระทบ)

กู้คืนผ่าน Termux (กรณีเปิดหลังร้านไม่ได้)
1) กด CTRL+c หยุด ED POS
2) cp ~/ed-pos/data.json ~/ed-pos/data-before-restore.json   (เก็บของเดิมไว้)
3) cp ~/storage/downloads/ed-pos-backup.json ~/ed-pos/data.json
4) node server.js

14. IP และเราเตอร์
================================================

- IP ดูได้จากหน้าจอ Termux ตอนรัน node server.js
  (บรรทัด "สั่งอาหาร : http://...")
- IP อาจเปลี่ยนเองเมื่อ: เราเตอร์รีสตาร์ท, ปิดเครื่องนาน,
  มีอุปกรณ์มาต่อ Wi-Fi เยอะ, Android สุ่มที่อยู่เครื่อง
- ถ้า IP เปลี่ยน: มือถือเข้าลิงก์เดิมไม่ได้ เครื่องสำรองหาเครื่องหลักไม่เจอ
  เครื่องพิมพ์ที่เปลี่ยน IP จะพิมพ์ไม่ออก

แนะนำ: ล็อก IP ในเราเตอร์ (ทำครั้งเดียว)
- เมนูในเราเตอร์มักชื่อ DHCP Reservation / Static IP / จอง IP
- ล็อก: แท็บเล็ตหลัก เครื่องสำรอง เครื่องพิมพ์ 2 เครื่อง
- บนแท็บเล็ตทั้งสองเครื่อง ปิด MAC แบบสุ่มก่อน:
  Wi-Fi → แตะชื่อ Wi-Fi ร้าน → ความเป็นส่วนตัว → ใช้ MAC ของอุปกรณ์

ล็อกแล้ว เปิดร้านทุกวันไม่ต้องเช็ก IP อีก

- พิมพ์ termux-wake-lock ทุกครั้งที่เปิด Termux ใหม่

- จอไม่ดับ: ตัวเลือกสำหรับนักพัฒนา → ไม่ล็อกหน้าจอขณะชาร์จ

เปิดโปรแกรมเองตอนเปิดเครื่อง (Termux:Boot)
- ติดตั้ง Termux:Boot จาก F-Droid แล้วเปิดแอปนี้ 1 ครั้ง
- ใน Termux พิมพ์ทีละบรรทัด:
    mkdir -p ~/.termux/boot
    printf '#!/data/data/com.termux/files/usr/bin/sh\ntermux-wake-lock\ncd ~/ed-pos && node server.js\n' > ~/.termux/boot/start-pos.sh
    chmod +x ~/.termux/boot/start-pos.sh
- เลือกเปิดอัตโนมัติแค่ ED POS หรือ OrderPin อย่างใดอย่างหนึ่ง

16. เคล็ดลับการพิมพ์ใน Termux
================================================

- คัดลอกคำสั่งจากแชทหรือคู่มือนี้ แล้วกดค้างใน Termux → Paste
  แม่นกว่าพิมพ์เอง
- แถบปุ่มดำด้านบนแป้นพิมพ์: ESC  /  —  CTRL  ALT  ลูกศร
- CTRL+c = กด CTRL บนแถบดำ แล้วกดตัว c = หยุดโปรแกรม
- ปุ่ม ⇥ (Tab) จะแสดงรายการคำสั่งยาวๆ กด CTRL+c เพื่อออก
- ลูกศรขึ้น = เรียกคำสั่งที่เคยพิมพ์

พิมพ์ผิดที่เจอบ่อย
  ผิด                     ถูก
  is ...                  ls ...       (แอล ไม่ใช่ ไอ)
  cd~                     cd ~         (ต้องเว้นวรรค)
  donwloads               downloads
  ~storage                ~/storage
  unzip ~o                unzip -o     (ขีดกลาง ไม่ใช่ตัวหยัก)
  -standby                --standby    (ขีดกลาง 2 ตัว)

17. แก้ปัญหา
================================================

ลืมรหัสเจ้าของร้าน
- ที่เครื่องหลัก หยุดโปรแกรม (CTRL + c) แล้วพิมพ์
    cd ~/ed-pos
    node server.js --reset-pin
    node server.js
- เปิดหลังร้าน จะให้ตั้งรหัสเจ้าของร้านใหม่ แล้วตั้งรหัสพนักงานใหม่ด้วย
  (ระหว่างนี้หน้าสั่งอาหารใช้ไม่ได้ จนกว่าจะตั้งรหัสใหม่) ข้อมูลบิลและเมนูไม่หาย

มือถือเปิดลิงก์ไม่ได้
- เครื่องหลักยังรัน Termux อยู่ไหม (ดูแจ้งเตือน Termux)
- มือถือต่อ Wi-Fi ร้านเดียวกันไหม (ไม่ใช่เน็ตมือถือ)
- IP เปลี่ยนหรือเปล่า (หัวข้อ 14)

หน้าจอขึ้นแถบแดง "ขาดการเชื่อมต่อเซิร์ฟเวอร์"
- โปรแกรมบนเครื่องหลักหยุด → เปิด Termux → node server.js
- ถ้าเครื่องหลักพัง → ดูหัวข้อ 10

เครื่องพิมพ์ไม่ออก
- เครื่องพิมพ์เปิดอยู่ มีกระดาษ ไฟเครือข่ายติด
- หลังร้าน → เครื่องพิมพ์ → IP ถูกไหม → พิมพ์ทดสอบ
- พอร์ตปกติคือ 9100
- ตัวหนังสือแคบหรือล้นกระดาษ → เปลี่ยนขนาดกระดาษ 58/80 มม.

สั่งแล้วไม่ขึ้นจอครัว
- หลังร้าน → เมนู → แก้เมนูนั้น → เปิด "ขึ้นจอครัว"
- เครื่องดื่ม/ของหวาน ปิดไว้โดยตั้งใจ
- ถ้าเพิ่งอัปเดต ให้รีเฟรชจอครัว

ไม่มีปุ่มความเผ็ดตอนสั่ง
- หลังร้าน → ชุดตัวเลือก → ความเผ็ด → ติ๊กเมนูที่ต้องการ → บันทึก

จอครัวไม่มีเสียง
- กด "เสียง" ให้เป็นสีเหลือง และ "อ่านออกเสียง: เปิด"
- แตะหน้าจอ 1 ครั้งหลังรีเฟรช
- เพิ่มเสียงแท็บเล็ต/ลำโพงบลูทูธ

เครื่องสำรองขึ้นแดงในหลังร้าน
- เปิด Termux ที่เครื่องสำรอง → cd ~/ed-pos → node server.js
- ตั้งแบตเตอรี่ Termux เป็น "ไม่จำกัด"

ไม่ขึ้นปุ่ม "ใช้เครื่องสำรองแทน"
- ยังไม่ได้ใส่ IP ในหลังร้าน → เครื่องสำรอง
- หรือมือถือยังไม่เคยเปิดหน้าตอนที่สองเครื่องเปิดพร้อมกัน
- แก้เฉพาะหน้า: ไปที่เครื่องสำรอง เปิด http://localhost:3000
  แล้วกด "ใช้เครื่องนี้เป็นเครื่องหลัก"

ข้อความ error ใน Termux
  EADDRINUSE           มีโปรแกรมอื่นรันอยู่ (เช่น OrderPin) → CTRL+c ตัวนั้นก่อน
  node: not found      ยังไม่ได้ลง Node → pkg install nodejs -y
  cannot find ... .zip ชื่อไฟล์หรือที่อยู่ผิด → ls ~/storage/downloads
  No command ...       พิมพ์คำสั่งผิด → ดูตารางพิมพ์ผิดในหัวข้อ 16
  ...already exists (y/n)  ตอน termux-setup-storage → พิมพ์ y ได้ ไฟล์ไม่หาย
  repository error     termux-change-repo → เลือก Asia

ใบสั่งครัว (หลังร้าน > ใบสั่งครัว) — ตั้งแต่ ed-pos19
==================================================
ปรับหน้าตาใบสั่งที่พิมพ์ออกทุกเครื่อง (ครัว บาร์ หน้าร้าน) รวมถึงใบยกเลิกและใบพิมพ์ซ้ำ
ดูตัวอย่างทางขวาได้ทันที · เลือกเครื่องแล้วกด "พิมพ์ทดสอบ" · กด "บันทึกใบสั่งครัว" แล้วใช้กับออเดอร์ถัดไป
- ขนาดตัวอักษร: ชื่อโต๊ะ / ชื่อเมนู / ตัวเลือกและหมายเหตุ
- ภาษา: ไทย / EN / 2 ภาษา (ไทยตัวใหญ่ อังกฤษตัวเล็กข้างใต้) ใช้คำแปลจากหน้า "ชื่อภาษาอังกฤษ"
- หัวใบ: เวลา · ทานที่ร้าน/กลับบ้าน (กลับบ้าน = แถบดำ) · "สั่งเพิ่ม · รอบที่ 2" · ชื่อเครื่องพิมพ์
- รายการ: จำนวนหน้า/หลังชื่อ · ตัวเลือกต่อท้ายหรือแยกบรรทัด · หมายเหตุ/แพ้อาหารเป็นตัวหนาหรือแถบดำ
  · เส้นประคั่นจาน · รวมจำนวนจาน · ชื่อเมนูยาวขึ้นบรรทัดใหม่ให้เอง (ไม่บีบตัวอักษร)
- "ใบละจาน" = ตัดกระดาษทุกจาน มีเลข "ใบ 1/3" บนหัว
- "แยกตามหมวด" = หมวดละใบ เช่น ของทอด กับ เครื่องดื่ม ออกเครื่องหน้าร้านเครื่องเดียวกันแต่ได้คนละใบ
- "แยกตามหมวดใหญ่" = ใช้หมวดใหญ่ (หลังร้าน > หมวดหมู่) เช่น อาหาร 1 ใบ / เครื่องดื่ม (น้ำผลไม้ ชา กาแฟ น้ำอัดลม เบียร์) 1 ใบ
- ตั้งแยกแต่ละเครื่องได้ที่ หลังร้าน > เครื่องพิมพ์ > "การแบ่งใบ" (เช่น หน้าร้าน = แยกตามหมวด, ครัว = รวมใบเดียว)
  เลือก "ตามใบสั่งครัว" = ใช้ค่าที่ตั้งในหน้านี้

หน้าสั่งอาหาร (หลังร้าน > หน้าสั่งอาหาร)
- ธีมสี: คลาสสิก / มืด / เขียว / น้ำเงิน / ชมพู
- ขนาดปุ่มเมนู ขนาดตัวอักษร จำนวนคอลัมน์ (แท็บเล็ต/คอม)
- เปิด/ปิด ชื่อภาษาอังกฤษใต้ชื่อเมนู ราคาบนปุ่ม ช่องค้นหาเมนู
- เปิด/ปิด ปุ่ม "กลับต่างประเทศ" (ทานที่ร้าน / กลับบ้าน / กลับต่างประเทศ)
  จานกลับต่างประเทศ: ใบสั่งพิมพ์แถบดำ ">> กลับต่างประเทศ <<" จอครัวขึ้นหมายเหตุ ใบเสร็จมี "(กลับต่างประเทศ)"

ปิดช่องหมายเหตุบางเมนู (หลังร้าน > เมนู > แก้ไขเมนู > ครัวและการขาย > "ช่องหมายเหตุ")
- ปิดแล้ว ตอนสั่งเมนูนั้นจะไม่มีปุ่มหมายเหตุด่วนและช่องพิมพ์หมายเหตุ
- ข้อความท้ายใบ · เว้นกระดาษก่อนตัด · เสียงบี๊บ (เฉพาะเครื่องพิมพ์ที่มีลำโพง)
- ปุ่ม "ค่าเริ่มต้น" = กลับไปหน้าตาแบบเดิม

ราคาคนไทย — ตั้งแต่ ed-pos20
==================================================
บางเมนูมี 2 ราคาได้ (ราคาปกติ / ราคาคนไทย) เลือกทีละจานตอนสั่ง
ตั้งราคา: หลังร้าน > เมนู > แตะเมนู
- เมนูราคาเดียว: ใส่ช่อง "ราคาคนไทย" ข้างราคาเริ่มต้น (เว้นว่าง = มีราคาเดียว)
- เมนูที่ใช้ตารางราคา: มีตาราง "ราคาคนไทย" ใต้ตารางปกติ
  ช่องที่ไม่ใส่ = ใช้ราคาปกติ · "ลดจากราคาปกติทุกช่อง" ใส่จำนวนเงินแล้วกด "เติมทุกช่อง" เติมให้ทั้งตาราง
- ตัวเลือกที่บวกราคา (เช่น ไข่ดาว +10) บวกเท่าเดิมทั้งสองราคา
- รายการเมนูในหลังร้านแสดง "คนไทย xx ฿" ใต้ราคาปกติ
ตอนสั่ง: เมนูที่มีราคาคนไทยจะมีปุ่ม "ราคาปกติ / ราคาคนไทย" บนสุด
- โต๊ะที่มีจานราคาคนไทยอยู่แล้ว จานต่อไปเลือก "ราคาคนไทย" ให้เอง (เปลี่ยนได้)
- ในบิลฝั่งพนักงานมีป้ายเขียว "ราคาไทย" · ใบเสร็จ ใบแจ้งยอด ใบสั่งครัว และจอครัว ไม่บอก
- ราคาคิดตอนส่งออเดอร์ แก้ราคาเมนูทีหลัง จานที่สั่งไปแล้วไม่เปลี่ยน

- จอครัว: จานเหมือนกันเป๊ะในโต๊ะเดียว รอบเดียวกัน แสดงบรรทัดเดียว ×3 · แตะบรรทัดนั้น = เสร็จทั้งหมด
  ปิดได้ที่ 🎨 ปรับหน้าจอ > "รวมจานที่เหมือนกันเป๊ะในโต๊ะเป็นบรรทัดเดียว"
- อ่านออกเสียง: เมนูเดียวกันอ่านครั้งเดียวพร้อมยอดรวม เช่น "โต๊ะ 5 กะเพรา 4 ที่ หมูกรอบ 3 ที่ ไก่ 1 ที่"
  ปิดได้ที่ ⚙️ ตั้งค่าเสียง > "อ่านรวมเมนูเดียวกันในโต๊ะ" · ปุ่ม "▶ ลองฟังเสียง" มีตัวอย่าง

==================================================
ป้าย "คนไทย" ในครัว — ตั้งแต่ ed-pos24
==================================================
- จอครัว: จานที่สั่งราคาคนไทยมีป้ายเขียว "คนไทย" ต่อท้ายชื่อ (รวมแท็บ "เสร็จแล้ว")
  จานเดียวกันที่ราคาไทยกับราคาปกติ แยกบรรทัดกัน ไม่รวมกัน
- อ่านออกเสียง: "ไข่ดาว 3 ที่ คนไทย 2 ที่ ธรรมดา 1 ที่"
- ใบสั่งครัว (พิมพ์): พิมพ์ [คนไทย] ต่อท้ายชื่อจาน (เปิดไว้เป็นค่าเริ่มต้น · ปิดได้ที่ หลังร้าน > ใบสั่งครัว > "บอกจานราคาคนไทย")
- ใบเสร็จ ใบแจ้งยอดของลูกค้า ยังไม่บอกเหมือนเดิม

==================================================
ราคาบนใบสั่งครัว — ตั้งแต่ ed-pos25
==================================================
หลังร้าน > ใบสั่งครัว > "ราคา" (มีผลเฉพาะใบที่พิมพ์ จอครัวไม่แสดงราคา)
- ไม่แสดง
- ทุกจาน (ค่าเริ่มต้น): ราคาชิดขวาของแต่ละจาน (ราคา × จำนวน) + บรรทัด "รวม xxx ฿" ท้ายใบ
- เฉพาะจานคนไทย: ราคาเฉพาะจานที่สั่งราคาคนไทย ไม่มีรวมท้ายใบ
- ใบแยกของตัวเลือก (เช่น ไข่ดาวพิมพ์แยกที่หน้าร้าน) ไม่มีราคา เพราะราคารวมอยู่ในจานหลักแล้ว

==================================================
ราคาคนไทยไม่แยกไซส์ — ตั้งแต่ ed-pos27
==================================================
สำหรับเมนูตารางราคา (เช่น เนื้อสัตว์ × ขนาด S/M/L) ที่ราคาคนไทยมีราคาเดียว ไม่มีไซส์
ตั้งค่า: หลังร้าน > เมนู > แตะเมนู > ตาราง "ราคาคนไทย" > ช่อง "ราคาคนไทย" เลือก "ไม่แยกตามขนาด (ราคาตามเนื้อสัตว์)"
- ตารางราคาไทยเหลือแค่ตามเนื้อสัตว์ ใส่ราคาแต่ละเนื้อสัตว์ (ตัวจางในช่อง = ราคาปกติไซส์ถูกสุด)
- "ลดจากราคาปกติที่ถูกสุด" เช่น 50 → ราคาไทย = ราคาไซส์ถูกสุดของเนื้อสัตว์นั้น − 50 บาท
- เนื้อสัตว์ที่ไม่ใส่ราคาไทย = ไม่มีราคาคนไทย (สั่งราคาไทยไม่ได้)
- ถ้ามีกลุ่มเดียวในตาราง เลือก "ไม่แยกตาม…" = ราคาคนไทยราคาเดียว
ตอนสั่ง: กด "ราคาคนไทย" → ปุ่มเลือกขนาดหายไป ไม่ต้องเลือก · เนื้อสัตว์ผสม = ราคาของเนื้อสัตว์ที่แพงสุด
- ตัวเลือกที่บวกราคา (เช่น ไข่ดาว +10) บวกเหมือนเดิม
- จอครัวและใบสั่งไม่มีไซส์ มีป้าย "คนไทย" แทน

==================================================
แอป ED POS บน Android — ตั้งแต่ ed-pos28
==================================================
ใช้แทนการเปิดหน้าเว็บใน Chrome: เปิดเต็มจอ จอไม่ดับ ล็อกแอปได้ ใส่ IP ครั้งเดียว
- ติดตั้ง: ดาวน์โหลด ed-pos-app.apk จากหน้า Releases ของ GitHub ed-pos-app → แตะติดตั้ง
- เปิดครั้งแรก: ใส่ IP เครื่องหลัก (เช่น 192.168.1.34) และเครื่องสำรอง · เลือก หน้าสั่งอาหาร / จอครัว / หลังร้าน
- แก้ตั้งค่า: แตะมุมซ้ายบนของจอ 5 ครั้งติดกัน → ใส่รหัสเจ้าของร้าน
- เครื่องหลักไม่ตอบ: แอปลองเครื่องสำรอง · ไม่ได้ทั้งคู่ ลองใหม่เองทุก 5 วินาที
- จอครัวอ่านออกเสียงด้วยเครื่องอ่านของ Android (ต้องมีเสียงภาษาไทยของ Google)
- ปุ่มดาวน์โหลด/ส่งออกเมนู บันทึกลงโฟลเดอร์ Download · ปุ่มเลือกไฟล์ใช้ได้ตามปกติ
- ปุ่ม ⛶ เต็มจอถูกซ่อนในแอป (แอปเต็มจอเองอยู่แล้ว)
เซิร์ฟเวอร์ต้องเป็น ed-pos28 ขึ้นไป (มีไฟล์ public/app-bridge.js) เสียงอ่านและปุ่มส่งออกเมนูจึงทำงานในแอป
หน้าเว็บใน Chrome ยังใช้ได้เหมือนเดิม ไม่มีอะไรเปลี่ยน


ยอดขาย (หลังร้าน > ยอดขาย) — ส่วนที่เพิ่ม
- ตัวเลขยอดขาย / บิล / เฉลี่ยต่อบิล มี ▲▼ เทียบช่วงก่อนหน้า
  ดูวันเดียว = เทียบวันเดียวกันของสัปดาห์ก่อน · ดูหลายวัน = เทียบช่วงยาวเท่ากันก่อนหน้า
  ดูวันนี้ (ร้านยังเปิด) = เทียบยอดถึงชั่วโมงเดียวกันของสัปดาห์ก่อน
- "ช่วงเวลาขายดี" (ดู 7 วันขึ้นไป): ตารางวันจันทร์–อาทิตย์ × ชั่วโมง สีเข้ม = ขายดี ชี้ที่ช่องเพื่อดูยอดเฉลี่ย
- "เมนูที่ขายไม่ออก" (ดู 7 วันขึ้นไป): เมนูที่เปิดขายแต่ไม่มีคนสั่งเลย แยกตามหมวด + 10 เมนูที่ขายน้อยสุด

สรุปยอดเข้า LINE (หลังร้าน > สรุปยอดเข้า LINE)
- ส่งสรุปยอดของวันเข้า LINE ทุกวันตามเวลาที่ตั้ง (เครื่องหลักต้องต่ออินเทอร์เน็ต)
- ต้องมี LINE Official Account ของร้าน (ฟรี) และเปิด Messaging API · วิธีตั้งค่าอยู่ในหน้านั้น
- เครื่องหลักปิดอยู่ตอนถึงเวลา → ส่งตอนเปิดเครื่องในวันเดียวกัน · ส่งไม่สำเร็จ → ลองใหม่ทุก 10 นาที
- กด "ส่งทดสอบตอนนี้" เพื่อลองส่งยอดของวันนี้ได้ทุกเมื่อ

ความปลอดภัยเครื่องสำรอง
- เครื่องหลักส่งข้อมูลร้านให้เฉพาะเครื่องสำรองที่จับคู่แล้วเท่านั้น (เครื่องอื่นใน Wi-Fi เดียวกันดึงข้อมูลไม่ได้)
- เครื่องสำรองที่เคยคัดลอกข้อมูลแล้ว: อัปเดตโปรแกรมทั้ง 2 เครื่อง แล้วใช้ต่อได้เลย ไม่ต้องจับคู่ใหม่
- เครื่องสำรองใหม่: เปิดหน้าเว็บของเครื่องสำรอง (http://IP-เครื่องสำรอง:3000) ใส่รหัสเจ้าของร้านของเครื่องหลัก กด "จับคู่" ครั้งเดียว
- อัปเดตโปรแกรมต้องทำทั้ง 2 เครื่อง ถ้าอัปเดตแค่เครื่องหลัก เครื่องสำรองรุ่นเก่าจะคัดลอกข้อมูลไม่ได้

พนักงานรายคน (หลังร้าน > รหัสผ่าน)
- เพิ่มพนักงาน: ใส่ชื่อ + รหัส 4 หลัก (รหัสทุกคนห้ามซ้ำกัน) ติ๊ก "หัวหน้า" ถ้าให้อนุมัติการยกเลิกทั้งโต๊ะได้
- พนักงานใส่รหัสของตัวเองที่หน้าสั่งอาหาร ระบบบันทึกชื่อไว้กับ จานที่สั่ง / จานที่ยกเลิก / โต๊ะที่ยกเลิก / การรับเงิน
- เปลี่ยนคนที่เครื่องเดียวกัน: หน้าเลือกโต๊ะ > ปุ่ม "👤 ชื่อ · เปลี่ยนคน" มุมขวาล่าง
- ดูสรุปที่ ยอดขาย > พนักงาน และรายการยกเลิก (โดยใคร อนุมัติโดยใคร) ใต้ตารางบิล
- "ยกเลิกทั้งโต๊ะต้องให้หัวหน้าอนุมัติ": พนักงานที่ไม่ใช่หัวหน้า ต้องให้หัวหน้าหรือเจ้าของร้านใส่รหัสในหน้ายกเลิก
- รหัสรวมพนักงาน (แบบเดิม) ยังใช้ได้ แต่บันทึกเป็น "พนักงาน (รหัสรวม)" ไม่รู้ว่าใคร · ตั้งรายคนครบแล้วควรยกเลิกรหัสรวม
- ลบพนักงาน/เปลี่ยนรหัส: เครื่องที่คนนั้นใส่รหัสไว้ต้องใส่รหัสใหม่ · ชื่อในบิลเก่ายังอยู่

แจ้งเตือนทันทีเข้า LINE (หลังร้าน > สรุปยอดเข้า LINE > แจ้งเตือนทันที)
- เครื่องพิมพ์พิมพ์ไม่ออก (และแจ้งเมื่อกลับมาพิมพ์ได้)
- เครื่องสำรองหลุดเกิน 2 นาที (และแจ้งเมื่อกลับมา)
- เครื่องสำรองรับงานแทนเครื่องหลัก
- ยกเลิกทั้งโต๊ะ (โต๊ะ จาน มูลค่า เหตุผล ใครยกเลิก ใครอนุมัติ)
- ปิด/เปิดแต่ละเรื่องได้ · กด "ทดสอบแจ้งเตือน" เพื่อลองส่ง

ประวัติการสั่ง (หน้าสั่งอาหาร > ปุ่ม "📋 ประวัติการสั่ง" บนหน้าเลือกโต๊ะ)
- ดูบิลของวันนี้ หรือย้อนหลังได้ 7 วัน · กรอง จ่ายแล้ว / ยกเลิก / เปิดอยู่ · ค้นหาด้วยชื่อโต๊ะหรือชื่อเมนู
- แตะบิลเพื่อดูรายการแต่ละรอบที่สั่ง (เวลา ใครสั่ง) จานที่ยกเลิก (ใครยกเลิก) การรับเงิน (วิธีจ่าย ใครรับ เลขใบเสร็จ)
- พิมพ์ใบเสร็จซ้ำได้จากในบิล · บิลที่ยังเปิดอยู่กด "เปิดโต๊ะนี้" ได้
- ร้านที่เปิดเลยเที่ยงคืน: บิลก่อนเที่ยงคืนอยู่ที่ "เมื่อวาน"
