เมนู

แตะเมนูเพื่อแก้ราคา ตัวเลือก และที่พิมพ์ใบสั่ง ปิดสวิตช์เมื่อของหมด พนักงานจะสั่งเมนูนั้นไม่ได้จนกว่าจะเปิดใหม่

ชุดตัวเลือก

ตั้งกลุ่มตัวเลือกที่ใช้ซ้ำหลายเมนู เช่น ความเผ็ด หรือการแพ้อาหาร ไว้ที่เดียว แก้ตรงนี้แล้วทุกเมนูที่ใช้ชุดนี้เปลี่ยนตาม

หมายเหตุด่วน

ปุ่มหมายเหตุที่ขึ้นทุกเมนูตอนสั่ง ไม่มีผลกับราคา แตะ × เพื่อลบ

หมวดหมู่

ลำดับตรงนี้คือลำดับบนหน้าสั่งอาหาร เปลี่ยนชื่อหมวดแล้วเมนูในหมวดจะย้ายตามให้เอง

หมวดใหญ่ แถบซ้ายของหน้าสั่งอาหาร

รวมหลายหมวดไว้ในหมวดใหญ่เดียว เช่น อาหาร = ข้าว เส้น ผัด แกง แตะหมวดใหญ่แล้วจะเห็นเมนูทุกหมวดย่อยแบ่งเป็นหัวข้อ ถ้าไม่ตั้งหมวดใหญ่เลย แถบซ้ายจะแสดงทุกหมวดเหมือนเดิม · หมวดที่ยังไม่ได้เลือกหมวดใหญ่จะไปอยู่ใน "อื่นๆ"

หมวด

ชื่อภาษาอังกฤษ

ใช้กับใบแจ้งยอดและใบเสร็จภาษาอังกฤษ คำเดียวกันแปลครั้งเดียว เช่น "หมู" ใช้ได้ทุกเมนู คำที่ยังไม่แปลจะพิมพ์เป็นภาษาไทย หน้าสั่งอาหาร จอครัว และใบสั่งในครัวยังเป็นภาษาไทยเหมือนเดิม

ตัวอักษรสีจางในช่อง = คำแนะนำ ยังไม่ถูกใช้จนกว่าจะกดเติมหรือพิมพ์เอง · ตรวจคำแนะนำก่อนบันทึก ให้ตรงกับอาหารของร้าน

การชำระเงิน

เครื่องพิมพ์

เพิ่มเครื่องพิมพ์ที่ต่อ LAN/Wi-Fi ได้ไม่จำกัด เช่น ครัว หน้าร้าน บาร์น้ำ แล้วเลือกว่าเมนูไหนออกเครื่องไหน (เมนูเดียวออกหลายเครื่องได้) ดู IP ได้จากใบทดสอบที่เครื่องพิมพ์พิมพ์เองตอนกดปุ่มค้าง และควรล็อก IP ไว้ในเราเตอร์

ใบเสร็จ

พิมพ์ใบสั่งทุกครั้งที่ส่งออเดอร์ปิดถ้าใช้จอครัวอย่างเดียว (ใบเสร็จยังพิมพ์ได้ตามปกติ)

เมนูไหนออกเครื่องไหน

ติ๊กได้หลายเครื่องต่อเมนู ติ๊กที่ชื่อหมวดเพื่อเลือกทั้งหมวด เมนูที่ไม่ติ๊กเลยจะไม่พิมพ์ใบสั่ง

จอครัว

มีจอครัวได้หลายจอ เช่น จอครัว กับ จอบาร์น้ำ แต่ละจอแสดงเฉพาะเมนูของตัวเอง เปิดลิงก์ของจอนั้นบนแท็บเล็ตที่วางไว้ หรือเลือกจอจากเมนูตั้งค่าบนหน้าจอครัว

เมนูไหนขึ้นจอไหน

เมนูที่ไม่ติ๊กเลยจะไม่ขึ้นจอ ถือว่าเสร็จทันทีที่สั่ง (เช่น เครื่องดื่มที่หน้าร้านทำเอง ใช้ใบที่พิมพ์ออกแทน)

เครื่องพิมพ์พิมพ์ไม่ออกแจ้งครั้งเดียวต่อรอบ และแจ้งอีกครั้งเมื่อกลับมาพิมพ์ได้
เครื่องสำรองหลุดไม่ได้คัดลอกข้อมูลเกิน 2 นาที · แจ้งเมื่อกลับมาด้วย

ยกเลิกทั้งโต๊ะบอกโต๊ะ จำนวนจาน มูลค่า เหตุผล และใครเป็นคนยกเลิก

วิธีตั้งค่า (ทำครั้งเดียว)

  1. เข้า manager.line.biz สร้าง LINE Official Account ของร้าน (แพ็กเกจฟรีก็ได้)
  2. ในหน้าตั้งค่าของ LINE OA เลือก Messaging API แล้วกดเปิดใช้
  3. เข้า developers.line.biz เลือก channel ของร้าน > แท็บ Messaging API > Channel access token กด Issue แล้วคัดลอกมาวางด้านบน
  4. เจ้าของร้าน (และคนที่อยากได้รับ) สแกน QR ในแท็บเดียวกันเพื่อเพิ่ม LINE OA เป็นเพื่อน
  5. กด บันทึก แล้ว ส่งสรุปยอดทดสอบ และ ทดสอบแจ้งเตือน

เครื่องสำรอง

ให้มือถือหรือแท็บเล็ตอีกเครื่องคัดลอกข้อมูลจากเครื่องหลักทุก 2 วินาที ถ้าเครื่องหลักพัง กดปุ่มเดียวให้เครื่องสำรองรับงานแทน โต๊ะที่เปิดค้างอยู่ไม่หาย

ที่อยู่ของสองเครื่อง

หน้าจอสั่งอาหารและจอครัวใช้ข้อมูลนี้หาเครื่องสำรองตอนเครื่องหลักไม่ตอบ ควรล็อก IP ทั้งสองเครื่องไว้ในเราเตอร์

ตั้งเครื่องสำรอง

ทำครั้งเดียวบนเครื่องที่สอง ใช้โฟลเดอร์ ed-pos ชุดเดียวกับเครื่องหลัก

  1. ติดตั้งแอป MAMA POS บนเครื่องที่สอง
  2. เปิดแอป หน้าตั้งค่า เลือก "เครื่องนี้เป็นเซิร์ฟเวอร์: เครื่องสำรอง" แล้วใส่ IP เครื่องหลัก
  3. เปิดหน้าเว็บของเครื่องสำรอง ใส่รหัสเจ้าของร้านเพื่อจับคู่ (ครั้งเดียว)
  4. กลับมาหน้านี้ สถานะด้านบนจะขึ้นว่าเครื่องสำรองเชื่อมแล้ว
  1. ลง Termux และ Node.js เหมือนเครื่องหลัก แล้วคัดลอกโฟลเดอร์ ed-pos ไปไว้
  2. ใน Termux พิมพ์ cd ~/ed-pos && termux-wake-lock && node server.js --standby 192.168.1.50:3000
  3. กลับมาหน้านี้ สถานะด้านบนจะขึ้นว่าเครื่องสำรองเชื่อมแล้ว
  4. ครั้งต่อไปพิมพ์แค่ node server.js เครื่องจะจำได้เองว่าเป็นเครื่องสำรอง (ใส่ใน Termux:Boot ได้เหมือนเครื่องหลัก)

สำรองข้อมูล

กู้คืนข้อมูล

แทนที่ข้อมูลทั้งร้าน (เมนู การตั้งค่า ผังโต๊ะ บิล ยอดขาย) ด้วยไฟล์สำรอง · ข้อมูลปัจจุบันถูกเก็บไว้ในเครื่องหลักก่อนทุกครั้ง ย้อนกลับได้จากรายการด้านล่าง · รหัส PIN ใช้ของปัจจุบัน ไม่ต้องตั้งใหม่ · ถ้าอยากได้เฉพาะเมนูคืน ใช้ เมนู > นำเข้าเมนูจากไฟล์

ไฟล์ที่ดาวน์โหลดไว้ไฟล์ ed-pos-วันที่.json จากปุ่มดาวน์โหลดด้านบน (บนแท็บเล็ตอยู่ในโฟลเดอร์ Download)
สำรองในเครื่องหลักสำรองอัตโนมัติวันละไฟล์ (30 วัน) และข้อมูลก่อนกู้คืนแต่ละครั้ง

รหัสผ่าน

รหัสตัวเลข 4 หลักสำหรับเข้าหน้าสั่งอาหารและหลังร้าน จอครัวไม่ต้องใส่รหัส · หลังร้านล็อกเองเมื่อไม่ได้แตะ 10 นาที

พนักงานรายคน · หน้าสั่งอาหาร

แต่ละคนมีรหัสของตัวเอง ระบบจะบันทึกว่าใครสั่ง ใครยกเลิก ใครรับเงิน ดูได้ที่ ยอดขาย > พนักงาน · หัวหน้า อนุมัติการยกเลิกทั้งโต๊ะได้

ยกเลิกทั้งโต๊ะต้องให้หัวหน้าอนุมัติพนักงานที่ไม่ใช่หัวหน้า ต้องให้หัวหน้าหรือเจ้าของร้านใส่รหัสก่อนยกเลิกทั้งโต๊ะ · ปิดโต๊ะว่างไม่ต้องอนุมัติ

รหัสรวมพนักงาน · ไม่รู้ว่าใครเป็นคนทำ

รหัสเจ้าของร้าน · หลังร้าน

ใช้เข้าได้ทุกหน้า อย่าบอกพนักงาน เปลี่ยนแล้วเครื่องอื่นที่เปิดหลังร้านอยู่ต้องใส่รหัสใหม่

ออกจากระบบทุกเครื่องทุกมือถือ/แท็บเล็ตที่เปิดหน้าสั่งอาหารอยู่ ต้องใส่รหัสใหม่ เช่น ตอนทำมือถือหาย หรือพนักงานลาออก (ควรเปลี่ยนรหัสพนักงานด้วย)
