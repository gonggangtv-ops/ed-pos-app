# MAMA POS — แอปหน้าจอร้าน Mama Mia Bangkok (Android)

ชื่อแอปและโลโก้ร้าน · ระบบเบื้องหลังคือ ED POS

แอปเปิดหน้า ED POS (หน้าสั่งอาหาร / จอครัว / หลังร้าน) แบบเต็มจอ จอไม่ดับ
และ**เป็นเซิร์ฟเวอร์ของร้านเองได้** (ไม่ต้องมี Termux) — เลือก "เครื่องนี้ทำหน้าที่: เครื่องหลัก / เครื่องสำรอง" ในหน้าตั้งค่า

## เซิร์ฟเวอร์ในแอป
- **เครื่องหลัก:** เปิดแอป → ตั้งค่า → เครื่องหลัก → บันทึก · หน้าตั้งค่าแสดง IP ของเครื่องนี้ไว้ใส่ในแท็บเล็ตเครื่องอื่น
- **เครื่องสำรอง:** เลือก เครื่องสำรอง แล้วใส่ IP เครื่องหลัก → เปิดหน้าเว็บเครื่องสำรองแล้วใส่รหัสเจ้าของร้านเพื่อจับคู่ (ครั้งเดียว)
- เซิร์ฟเวอร์ทำงานเบื้องหลังตลอด (มีแถบแจ้งเตือนค้าง) ปิดจอได้ และ**เปิดเองเมื่อเปิดเครื่อง/อัปเดตแอป**
- กด "อนุญาตให้ทำงานตลอด" ในหน้าตั้งค่า (ไม่ให้ Android ปิดเพื่อประหยัดแบต) และเสียบชาร์จเครื่องหลักไว้
- ย้ายจาก Termux: หลังร้านเดิม > สำรองข้อมูล > ดาวน์โหลด → ปิด Termux → ตั้งแอปเป็นเครื่องหลัก → ตั้งรหัส → หลังร้าน > สำรองข้อมูล > กู้คืนจากไฟล์
- ลืมรหัสเจ้าของร้าน: ที่เครื่องหลัก แตะมุมซ้ายบน 5 ครั้ง → "ลืมรหัสเจ้าของร้าน?" (แจ้งเข้า LINE ของร้าน)
- **ข้อมูลร้านอยู่ในแอป ถ้าถอนการติดตั้งแอป ข้อมูลหาย** — ดาวน์โหลดไฟล์สำรองเก็บไว้เป็นระยะ / ใช้เครื่องสำรอง
- อัปเดตโปรแกรม ED POS = ติดตั้งแอปรุ่นใหม่ (ไฟล์เซิร์ฟเวอร์อยู่ใน `app/src/main/assets/edpos/`) ข้อมูลร้านไม่หาย

## ติดตั้ง
1. บนแท็บเล็ต เปิด **Releases** ของที่เก็บนี้ → ดาวน์โหลด `ed-pos-app.apk` รุ่นล่าสุด
2. แตะไฟล์เพื่อติดตั้ง (ครั้งแรก Android จะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" จาก Chrome / ไฟล์)
3. เปิดแอป ใส่ IP เครื่องหลัก (เช่น `192.168.1.34`) และเครื่องสำรอง เลือกว่าเครื่องนี้เป็นหน้าไหน → บันทึก

รุ่นใหม่ติดตั้งทับได้เลย การตั้งค่าไม่หาย · ต้องใช้ Android 8 ขึ้นไป

## ใช้งาน
- **แก้ตั้งค่า:** แตะมุมซ้ายบนของจอ 5 ครั้งติดกัน → ใส่รหัสเจ้าของร้าน
- **เครื่องหลักไม่ตอบ:** แอปลองเครื่องสำรองให้เอง ไม่ได้ทั้งคู่ขึ้นหน้า "ติดต่อเซิร์ฟเวอร์ไม่ได้" และลองใหม่ทุก 5 วินาที
- **ล็อกแอป:** ติ๊กในหน้าตั้งค่า (ต้องเปิด ตั้งค่า Android → ความปลอดภัย → ปักหมุดแอป ก่อน)
- **เสียงอ่านภาษาไทยจอครัว:** ใช้เครื่องอ่านออกเสียงของ Android ถ้าไม่มีเสียงไทย ตั้งค่า → เสียงอ่าน → Google → ติดตั้งภาษาไทย
- **ไฟล์ที่ดาวน์โหลด** (สำรองข้อมูล ส่งออกเมนู) อยู่ในโฟลเดอร์ Download

ต้องใช้ ED POS ตั้งแต่ ed-pos28 (มี `app-bridge.js`) เพื่อให้เสียงอ่านและปุ่มส่งออกเมนูทำงานในแอป

## สำหรับนักพัฒนา
- โค้ด: `app/src/main/java/com/edpos/app/MainActivity.java` (WebView + TextToSpeech + บันทึกไฟล์) และ `app/src/main/assets/app.html` (หน้าตั้งค่า/ออฟไลน์)
- เซิร์ฟเวอร์ในแอป: `NodeService.java` (foreground service กระบวนการ `:node`) + `app/src/main/cpp/native-lib.cpp` (เรียก `node::Start`) ใช้ [nodejs-mobile](https://github.com/nodejs-mobile/nodejs-mobile) ซึ่ง workflow ดาวน์โหลดไว้ที่ `app/libnode/` ตอน build
- ไฟล์เซิร์ฟเวอร์ ED POS: `app/src/main/assets/edpos/` (ห้ามใส่ `data.json` — มีข้อมูลร้านและรหัส)
- กิ่ง `claude/*` สร้างรุ่นทดสอบ (Pre-release) · `main` สร้างรุ่นจริง (Latest)
- สร้าง APK อัตโนมัติด้วย GitHub Actions (`.github/workflows/build.yml`) ทุกครั้งที่ push ขึ้น main → แนบไว้ที่ Releases
- เซ็นด้วย `app/edpos-release.jks` ตัวเดียวกันทุกรุ่น (ห้ามเปลี่ยน ไม่งั้นติดตั้งทับไม่ได้)
