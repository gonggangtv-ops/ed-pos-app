# MAMA POS — แอปหน้าจอร้าน Mama Mia Bangkok (Android)

ชื่อแอปและโลโก้ร้าน · ระบบเบื้องหลังคือ ED POS

แอปเปิดหน้า ED POS (หน้าสั่งอาหาร / จอครัว / หลังร้าน) แบบเต็มจอ จอไม่ดับ
ตัวเซิร์ฟเวอร์ยังรัน `node server.js` ใน Termux บนแท็บเล็ตเครื่องหลักเหมือนเดิม

## ติดตั้ง
1. บนแท็บเล็ต เปิด **Releases** ของที่เก็บนี้ → ดาวน์โหลด `ed-pos-app.apk` รุ่นล่าสุด
2. แตะไฟล์เพื่อติดตั้ง (ครั้งแรก Android จะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" จาก Chrome / ไฟล์)
3. เปิดแอป ใส่ IP เครื่องหลัก (เช่น `192.168.1.34`) และเครื่องสำรอง เลือกว่าเครื่องนี้เป็นหน้าไหน → บันทึก

รุ่นใหม่ติดตั้งทับได้เลย การตั้งค่าไม่หาย · ต้องใช้ Android 8 ขึ้นไป

## ใช้งาน
- **แก้ตั้งค่า:** แตะมุมซ้ายบนของจอ 5 ครั้งติดกัน → ใส่รหัสเจ้าของร้าน
- **เครื่องหลักไม่ตอบ:** แอปลองเครื่องสำรองให้เอง ไม่ได้ทั้งคู่ขึ้นหน้า "ติดต่อเซิร์ฟเวอร์ไม่ได้" และลองใหม่ทุก 5 วินาที
- **ล็อกแอป:** ติ๊กในหน้าตั้งค่า (ต้องเปิด ตั้งค่า Android → ความปลอดภัย → ปักหมุดแอป ก่อน)
- **เสียงอ่านภาษาไทยจอครัว:** ใช้เครื่องอ่านออกเสียงของ Android ถ้าไม่มีเสียงไทย ตั้งค่า → เสียงอ่าน → Google → ติดตั้งภาษาไทย
- **ไฟล์ที่ดาวน์โหลด** (สำรองข้อมูล ส่งออกเมนู) อยู่ในโฟลเดอร์ Download

ต้องใช้ ED POS ตั้งแต่ ed-pos28 (มี `app-bridge.js`) เพื่อให้เสียงอ่านและปุ่มส่งออกเมนูทำงานในแอป

## สำหรับนักพัฒนา
- โค้ด: `app/src/main/java/com/edpos/app/MainActivity.java` (WebView + TextToSpeech + บันทึกไฟล์) และ `app/src/main/assets/app.html` (หน้าตั้งค่า/ออฟไลน์)
- สร้าง APK อัตโนมัติด้วย GitHub Actions (`.github/workflows/build.yml`) ทุกครั้งที่ push ขึ้น main → แนบไว้ที่ Releases
- เซ็นด้วย `app/edpos-release.jks` ตัวเดียวกันทุกรุ่น (ห้ามเปลี่ยน ไม่งั้นติดตั้งทับไม่ได้)
